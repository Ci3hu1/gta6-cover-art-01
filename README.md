# Leonida Nights Cover Studio

Turn any photo into GTA 6-style cover art: a hero-led multi-panel poster with a striped retro-chrome title, a neon script subtitle, and the complete magazine furniture — a 5-star press-quote band, VOL. pill, gold "ORIGINAL COVER ART" seal, tagline ribbon, and billing block with barcode. Eight layouts (including a true pop-out hero that breaks out of the grid and diagonal Slant cuts), six golden-hour grades, per-panel crop/position/flip, two-line cast role tags, an optional Poster Ink look, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Fully offline — photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a layout and grade, edit the caption, and export a PNG.

## Tests

```sh
node --test tests/cover.test.mjs
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
