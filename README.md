Palm Heat Cover Studio — an offline web app that turns any photo and a caption into GTA-style multi-panel poster cover art, exported as a PNG to share. Photos are inked like comic art (Sobel edges redrawn as thick black outlines, five flat poster tones, halftone dots in the shadows, paper grain), never just filtered: a hero-led grid keeps the lead face fully in frame, five colour grades (Vice Sunset, Neon Night, Golden Coast, Noir Ink, Teal Pink) restyle the same ink, and the title block carries Anton lettering with a black outline, a Pacifico neon subtitle, a five-star heat meter and a WANTED badge. Five layouts, per-panel photo assignment, drag to reframe, scroll to zoom, undo/redo, and one-click PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos never leave the machine; everything runs from static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## Tests

```sh
node tests/run.mjs
```
