# Leonida Nights — GTA 6 Cover Studio

A fully offline web app that turns any photo and caption into GTA 6-style cover art: clean photographic multi-panel posters with a pop-out hero, striped retro-chrome 3D lettering over the art, cast role tags, six gentle Vice sunset grades, and PNG export in 1080×1080, 1080×1350 and 1920×1080. Photos never leave the machine; the whole studio runs from static files with zero network requests.

Run it with `node serve.ts`, then open http://localhost:8080.
