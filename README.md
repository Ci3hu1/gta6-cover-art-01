# Palm Heat — GTA 6 Cover Studio

Turn any photo and a caption into GTA 6-style cover art: a multi-panel comic-grid poster with thick ink outlines, halftone shadows and a sunset or neon grade, exported as a PNG to share. It runs fully offline in a desktop browser — photos never leave the machine. Pick a grade, pick a layout, drop in up to six photos (or your own), crop each panel, and export in 1080×1080, 1080×1350 or 1920×1080.

Run it: `node serve.ts`, then open http://localhost:8080.
