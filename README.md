Palm Heat Cover Studio — an offline web app that turns any photo and a caption into GTA-style multi-panel poster cover art, exported as a PNG to share. Five layouts (four-panel grid, hero + three, full bleed, nine-panel grid, tilted snapshots), five gradient-map colour grades (Vice Sunset, Neon Night, Gold Hour, Teal Pink, Mono Noir), Anton display lettering with a Pacifico neon script subtitle, a heat-meter of stars and a badge ribbon, per-panel crop and positioning, undo/redo, film grain and vignette, and one-click PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos never leave the machine; everything runs from static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
